# 1.0.26 横屏适配

首页：横屏隐藏英文副标题，收紧品牌栏及迷你播放条。音乐库切换、标题/数量、刷新/导入、播放入口进入左侧栏；搜索、状态和ListView进入右侧栏。装饰卡片不占用横屏高度。

播放页：写真/歌词stage和transport改为横向分配空间，右侧控制放入fillViewport的ScrollView，短窗口可以滚动。设置菜单的高度也按可用屏高收紧。

页面状态：保存screen及local_mode，Activity因旋转重建后恢复页面，避免重建再次自动播放暂停中的音乐。播放服务继续独立运行。

验证：真实Android视图在API28和35上完成6项Robolectric原生图形测试。覆盖800×360、640×280，云盘及本地列表、歌曲行可见、底部迷你条、播放键和模式切换可见、写真/歌词切换、旋转页面恢复。截图使用测试歌曲和公开写真，仅用于内部检查。尚未实体手机验证。
